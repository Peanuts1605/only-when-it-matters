# Product brief

- **Person:** a small-team contest operator carrying several active submissions.
- **Promise:** routine delivery runs quietly; the few real boundaries arrive with one exact action.
- **First useful moment:** replay five events and see which two truly deserve interruption.
- **Primary journey:** event arrives → deterministic decision → idempotent record → exact escalation or silence.
- **Return value:** each run preserves context while reducing repeated attention tax.
- **Character:** calm, precise, and deliberately unimpressed by noisy automation.
- **Platform:** local-first Python/Strands vertical slice; public web judge console next.
- **Data sensitivity:** public-safe fixtures now; header-only metadata with explicit minimization later.
- **Commercial boundary:** no paid model, AWS service, or contest fee in this stage.
- **Non-goals:** sending replies, making eligibility decisions, or replacing human legal authority.
- **Falsifier:** the agent cannot distinguish a routine event from a real authority boundary across replay and retry.

**Product truth:** A contest operator loses focus when every automated update demands attention;
Only When It Matters produces an auditable queue that interrupts only for a verified human boundary,
and proves the attention saved rather than merely promising automation.

## Product bet

- Cheap-test stake: one local vertical slice and public-safe fixture set.
- Working-proof estimate: 85%.
- Eligibility estimate: 80%, pending entrant confirmation and official registration.
- 60-second judge comprehension estimate: 75% after the web console exists.
- User-return estimate: 55% until live adapters prove continued value.
- Most important unknown: whether deterministic quiet plus model-directed tools feels like a useful agent rather than a rules engine.
- Increase the bet when: a live adapter preserves the same boundary and a cold judge can reproduce the metric.
- End the bet when: model involvement cannot improve explanation or recovery without weakening the deterministic boundary.
